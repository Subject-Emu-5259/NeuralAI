# NeuralAI: The Generative AI Engine

**The High-Velocity Model for Your Entire Vibe Stack**

NeuralAI is the central intelligence engine for Harris Holdings. It is a highly tuned, DPO-aligned model designed for creative thinking, code optimization, and system architecture.

## 🧠 The Manifesto
NeuralAI doesn't just predict text; it operates the work. The goal is to create a multimodal generative system that can bridge the gap between idea and execution through both autoregressive reasoning and generative diffusion.

## 🛠️ Tech Stack (v5.5)
- **Model**: SmolLM2-360M-Instruct (DPO v10 Aligned)
- **Framework**: Flask (Core Service)
- **Terminal**: Integrated Web Terminal with full shell access
- **Cloud Storage**: Nextcloud Hub (via NeuralCloud WebDAV Client)
- **Database**: SQLite3
- **Inference**: PyTorch (CPU Optimized)

## 🏗️ Architecture
- **NeuralAI Core**: Handles chat, model inference, terminal sessions, and tool orchestration.
- **NeuralCloud (Nextcloud)**: Manages per-user isolated storage.
- **NeuralDrive Client**: Python abstraction layer for WebDAV operations.

## 🛠️ Core Components

### 1. NeuralAI Core
The central intelligence engine. A highly tuned, DPO-aligned model that understands the Founder's context, code optimization, and system architecture.

### 2. NeuralDrive (Cloud Storage File Server)
The intelligent data layer for all Harris Holdings projects.
- **API-Driven**: Managed via `neural_drive_service.py`.
- **Versioning**: Automatic snapshots of every edit.
- **Semantic Mapping**: Files are indexed for the AI to find "logic" rather than just "filenames".

### 3. Diffusion Engine (Beta)
The upcoming multimodal layer for generating UI mockups, branding assets, and visual logic maps.
