About the model

NeuralAI v2 is a PEFT/LoRA adapter trained on top of HuggingFaceTB/SmolLM2-360M-Instruct. It targets every attention and MLP projection (q,k,v,o,gate,up,down) with rank 16, alpha 32, dropout 0.05. Training was run for 3 epochs at learning rate 2e-4 over 363 curated DPO-style samples, completing in ~26 minutes.

The adapter is built and maintained by De'Andrew P. Harris as the intelligence backend for the NeuralAI / NeuralLabs product stack.

How to load it

import torch
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel

base = "HuggingFaceTB/SmolLM2-360M-Instruct"
adapter = "Subject-Emu-5259/NeuralAI"

tok = AutoTokenizer.from_pretrained(base)
model = AutoModelForCausalLM.from_pretrained(base, torch_dtype=torch.bfloat16)
model = PeftModel.from_pretrained(model, adapter)

What this Space is

A free-tier Static Space — pure HTML/CSS/JS, no server. The landing page you’re on is the model card. The chat demo talks to the public Hugging Face Inference API using the base SmolLM2-360M model (the LoRA adapter itself requires server-side PEFT merging, which isn’t available on the free Inference API).

For a live demo of the fine-tuned adapter, the repo supports a Gradio Space, but that requires Hugging Face PRO.
