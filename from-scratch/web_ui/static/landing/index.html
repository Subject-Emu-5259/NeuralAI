The Company

What we are building

🧠

Intelligence Engine

NeuralAI is the raw cognitive core — a high-density knowledge graph ("Neural-Brain") spanning physics, philosophy, geopolitics, and human history, served through a manager-worker orchestrator.

⚙️

Local-First by Design

Inference runs on-device via llmster + LM Studio, surviving reboots with a watchdog. No cloud lock-in, no vendor dependency — your intelligence stays on your machine.

🔗

Ecosystem Backbone

NeuralAI is the intelligence source behind NeuralLabs and the wider stack, connected through a Hybrid Link Gateway so frontend products inherit expert reasoning instantly.

Founded on a belief that accessible, aligned, and open intelligence should run anywhere — from a laptop to a production server — NeuralAI is engineered by DeAndrew P. Harris and the Neural team.

Features

Built for real work

🤖 Agentic Tool Use

Plain-English requests are routed to live web tools — search, fetch, browse, research, image, translate, summarize, and YouTube — before they ever hit the model.

💬 Google-Style Chat

A clean, fast web UI with streaming responses, conversation history, file handling, and an embedded terminal — no clutter, just the work.

🛡️ Aligned & Auditable

DPO-trained preference datasets and a documented alignment baseline keep outputs helpful, honest, and on-task.

Training

How the brain gets smarter

  • DPO v15 Complete. Trained a 597-pair preference dataset (3 epochs, 450 steps, loss 0.305) focused on debugging, logic, and multi-step reasoning.
  • Adapter live on Hugging Face. Adapter published to Subject-Emu-5259/NeuralAI and loadable by downstream apps.
  • NL→Tool Router. Plain-English web intents are classified client-side and routed to real tools — no need to memorize slash syntax.
  • Refinement pass. Raw tool output is cleaned and tightened before display, so answers read like prose, not boilerplate.
  • Expanding knowledge. Target domains (Modernity, advanced sociology, deeper biology) are queued for the next Neural-Brain expansion.
