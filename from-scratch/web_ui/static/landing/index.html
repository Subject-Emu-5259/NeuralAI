Features

Built for reasoning, not replies.

Agentic Web Tools

Ten live tools — search, fetch, browse, research, image, speak, summarize, translate, news, YouTube. Plain-English requests are routed before they hit the model.

Neural-Brain Graph

An expanded knowledge graph spanning quantum field theory, platonic philosophy, geopolitics, and human evolution — expert depth, not trivia.

Orchestrator

Manager-worker delegation for multi-step reasoning. The system plans, splits, and verifies instead of blurting a single answer.

DPO-Aligned Model

597 preference pairs trained for debugging, logic, and multi-step reasoning. Alignment gain of 56.73% over the v13 baseline.

Local-First Inference

SmolLM2-360M via llmster on port 1234 — pluggable to Ollama, OpenAI-compatible APIs, or local PyTorch. Your server, your weights.

Hybrid Link Gateway

The bridge that powers the NeuralLabs frontend. One clean protocol between the intelligence engine and the interface.

Training

How the brain gets smarter.

  1. SFT v15/v16 — supervised fine-tune on curated expert traces across physics, philosophy, and geopolitics.
  2. DPO v15 — 597 preference pairs, 3 epochs / 450 steps, loss 0.305, margin ~3.5. Adapter live on Hugging Face.
  3. NeuralLabs v13 DPO — checkpoint-69, validation loss 0.7232, alignment improvement 56.73% (active baseline).
  4. Continuous — dream-sequence memory compression feeds long-term context back into training topics.
