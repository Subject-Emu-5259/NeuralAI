The Company

What we are building

🧬

Owned Base Models

NeuralAI's Mamba family — K1 (130M), K2 (793M GGUF), and K3 (790M SSM in training) — are NeuralAI's first fully-owned base models. SSM architecture, locally fine-tuned, no dependency on external providers.

⚙️

Local-First by Design

Inference runs on-device via LM Studio running K2's Q4_K_M GGUF (460MB). Survives reboots with a watchdog. No cloud lock-in, no vendor dependency — your intelligence stays on your machine.

🔗

Ecosystem Backbone

NeuralAI is the intelligence source behind NeuralLabs and the wider stack, connected through a Hybrid Link Gateway so frontend products inherit expert reasoning instantly.

Founded on a belief that accessible, aligned, and open intelligence should run anywhere — from a laptop to a production server — NeuralAI is engineered by DeAndrew P. Harris and the Neural team.

Models

The Mamba Family

🧬 Mamba K1

130M parameters — First owned SSM base model. A new SFT v2 run is in progress using a vocabulary-friendly prompt format and assistant-only loss. After retraining it becomes the reference for K2 and K3 instruction tuning.

Hugging Face: Subject-Emu-5259/NeuralAI-Mamba-K1 · Status: SFT v2

🧬 Mamba K2

793M parameters — Scaled SSM base model, already quantized to Q4_K_M GGUF (460MB). It is wired into the live inference stack, but still needs full SFT before it will answer cleanly in chat.

Hugging Face: Subject-Emu-5259/NeuralAI-Mamba-K2 · Status: Base ready, SFT queued

🔬 Mamba K3

2.8B parameters — Largest NeuralAI base to date. Full SFT queued on 10K+ UltraChat samples with 500–1000 steps, followed by GGUF conversion and benchmarks.

Status: Base ready, SFT queued — Colab notebook available

The Mamba SSM architecture gives us linear O(n) complexity vs transformer attention's O(n²) — faster at length, memory-efficient, and fully owned by NeuralAI.
