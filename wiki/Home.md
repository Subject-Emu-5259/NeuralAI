# 🧠 NeuralAI-from-scratch Wiki Home

Welcome to the official wiki for **NeuralAI-from-scratch**! This repository powers a ChatGPT-style LLM and developer agent, built from the ground up with state-of-the-art training and an integrated tool ecosystem.

---

## 🚩 Project Overview
NeuralAI is a high-velocity, DPO-aligned, multimodal generative AI engine built for the "Harris Holdings" platform and led by De'Andrew Preston Harris. 

- **Description:** ChatGPT-style LLM built from scratch in PyTorch — Flash Attention, RoPE, KV-cache, streaming.
- **Live Demo:** [neuralai-deandrewharris.zocomputer.io](https://neuralai-deandrewharris.zocomputer.io)
- **Main repo:** [GitHub](https://github.com/Subject-Emu-5259/NeuralAI-from-scratch)


---

## 🏗️ Tech Stack & Language Composition
- **Languages:** Python (72.8%), HTML (12.9%), JavaScript (10.7%), CSS (2.7%), Shell, Jupyter Notebook, Jinja
- **Core Model:** SmolLM2-360M-Instruct, LoRA, DPO Aligned
- **Backend:** Python 3, Flask, PyTorch
- **Frontend:** Vanilla JS, HTML5, CSS3, Google Sans, JetBrains Mono Terminal
- **Database:** SQLite3 (conversations/data), Nextcloud Hub via NeuralCloud WebDAV (NeuralDrive)
- **Other:** Diffusion Engine for visual assets, SSE/live chat streaming, integrated developer tools

---

## 🌟 Key Features
- Local & fast multimodal text inference (LLM, code, math, QA)
- Live streaming chat UI (SSE-powered)
- Voice-to-voice conversation support
- Secure tiered authentication (Founder Mode, Guest Preview, Student Portal)
- Integrated web terminal & file browser
- Code execution sandbox
- RAG document indexing
- Cloud file storage (NeuralDrive)
- Tool chaining and agent actions in chat

---

## 🏋️‍♂️ Model Training & DPO Alignment
- SFT + DPO fine-tuning pipeline (QLoRA, LoRA adapters, 4-bit NF4)
- Training data: 579 samples (SFT + DPO pairs)
- DPO preferences: 232 pairs covering reasoning, math, code, system design
- Validation split: 20%, Final Loss: ~0.04
- Evaluation: Benchmarks for code quality, response helpfulness, latency, and safety
- Hardware: Optimized for edge/CPU, supports GPU (T4, Colab, RunPod)
